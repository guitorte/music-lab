# Arquivo: scripts das sessões de nov. 2026

Como foram rodados, com caminhos fixos do ambiente da sessão. Servem de registro e de fonte para extrair código; para uso, prefira `lib/` e `tools/`.

| Prefixo | Faixa / tarefa |
|---|---|
| `e1`–`e6`, `e3` | primeiras masters; `e3.py` tem os blocos de DSP (hoje em `lib/dsp.py`) |
| `q*`, `qm*` | Que nem eu ITA (correções e master) |
| `sk*` | AFLX_004 (skate punk) |
| `v*`, `w*`, `vm*` | Virada no Diabo: troca de palavras, stems exatos, master |
| `vr*` | Virada no Diabo (Remastered) + remoção de artefatos |
| `tp*` | TPTM (análise, linhas tonais, cadeia com estágio rápido) |
| `vv*` | Vai e Volta |
| `c*`, `cc*`, `cm*` | Coca_na: emendas, versões A/B, master |
| `ch*` | Marina Chinesa (sample) |
| `so*`, `pg*` | Soap Opera Thing: master e groove de pagode a partir dos stems |
| `md*`, `mr*`, `kit1` | Soap Opera Thing: MIDI com groove, render FluidSynth, kit de bateria |
| `mt*` | Mente: master aprovada (`mt4`), final editado (`mt5`), intro suave (`mt6`, `mt7`) |
| `dp*` | Mente DiP Extended |
| `rf*` | análise da referência ao vivo |
| `ai*`, `lay*`, `tim1` | faixa IA vs referência: equilíbrio, camadas, timbres |
| `rw*` | reescrita de arranjo (cópias limpas em `tools/arrange/`) |
| outros (`an*`, `g*`, `l*`, `n*`, `p*`, `r*`, `s*`, `t*`) | análises e tentativas intermediárias |
